Sobre

Sou desenvolvedor focado em criar soluções práticas: sistemas de gestão, automações de processos e integrações que economizam tempo real de quem trabalha com isso todo dia. Gosto de projetos que misturam front-end bem cuidado com lógica de backend sólida — desde dashboards com Next.js e Supabase até automações com Python e Selenium para sistemas que não têm API oficial.

Já desenvolvi desde painéis de cobrança e controle de parcelas com notificações automáticas via WhatsApp, até integrações web para consulta de notas fiscais e landing pages completas para negócios locais. Curioso por natureza, estou sempre testando novas ferramentas e formas mais eficientes de resolver problemas.
