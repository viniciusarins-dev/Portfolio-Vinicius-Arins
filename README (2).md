# Portfólio — Vinicius de Jesus Arins

Portfólio pessoal em HTML/CSS puro, single-page, sem build e sem dependências.

## Conteúdo

- `index.html` — página completa (hero, sobre, projetos, skills, contato)

## Como rodar localmente

Basta abrir o `index.html` no navegador. Não precisa de servidor nem instalação.

## Deploy

Publicado via [Netlify](https://netlify.com). Qualquer alteração no `index.html` desta branch principal atualiza o site automaticamente quando conectado ao Netlify via "Import from Git".
